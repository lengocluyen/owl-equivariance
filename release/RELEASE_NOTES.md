# v33-evidence-2026-11-11

Public packaging of existing code and descriptive evidence for **Evaluating the Semantic Consistency of Large Language Models for OWL Reasoning**.

## Included

- Python and Java research code, archived scripts, original v3.3 configuration and exact panel, and author working-tree Python tests.
- Descriptive answer/family/support/repeat summaries for all nine ontology sources and the unchanged manuscript figure-value traces.
- Release asset `owleq-v33-public-evidence.tar.gz`: unchanged benchmark contexts and raw/validated predictions for eight sources, the original all-nine-source scalar primary-outcome export, source/model hashes, runtime/build metadata, logs, and continuation provenance.
- File-level SHA-256 manifest and an asset checksum. The included frozen evidence files are not edited for the deposit.

## Important exclusions and qualifications

**HP/HPO-derived model-visible contexts, mappings, repeat contexts, and raw/validated prediction files are withheld pending redistribution clarification under the custom HPO terms.** The full original private tarball is not uploaded because it contains these files. HP numerical results and hashes remain public; the article's results are unchanged. See `docs/DATA_LICENSES.md` and the manifest's omissions list.

Historical regressions, adjusted contrasts, and inferential outputs are retained only for provenance and are **excluded article evidence**. The historical token-change covariate does not consistently use the same model's C0 reference. Do not interpret the presence of an archived analysis script or output as a correction of this issue. No new inference, statistical fit, bootstrap, descriptive reaggregation, or figure regeneration was performed for this release.

Unnecessary device identifiers, unrelated installed-model inventories, credentials/environment files, private manuscript drafts, and internal review/style notes are not uploaded. Complete upstream OWL distributions and model weights are not bundled. Data retain their upstream terms; the project code retains Apache-2.0.

The experiment's validity-threshold failures and continuation remain documented. The public deposit does not retroactively change preregistration status, establish statistical superiority, provide a DOI, or assert journal acceptance.
